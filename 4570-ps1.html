Solutions

↑ Problem

Solution 1. $G$ IS a field (it is $\mathbb{Q}(i)$).

All axioms not involving inverses (associativity, commutativity, distributivity) are inherited from $\mathbb{C}$, so we only check closure and inverses.

$\bullet$ Identities: $0=0+0i\in G$ and $1=1+0i\in G$.

$\bullet$ Closed under $+$: $(a+bi)+(c+di)=(a+c)+(b+d)i$, and $a+c,\,b+d\in\mathbb{Q}$.

$\bullet$ Closed under $\times$: $(a+bi)(c+di)=(ac-bd)+(ad+bc)i$, components in $\mathbb{Q}$.

$\bullet$ Additive inverse: $-(a+bi)=(-a)+(-b)i\in G$.

$\bullet$ Multiplicative inverse of $z=a+bi\neq 0$:

$z^{-1}=\frac{a-bi}{a^2+b^2}=\frac{a}{a^2+b^2}+\left(\frac{-b}{a^2+b^2}\right)i.$ Since $a,b\in\mathbb{Q}$ and $a^2+b^2$ is a positive rational, both parts lie in $\mathbb{Q}$, so $z^{-1}\in G$. Hence $G$ is a field. ∎

↑ Problem

Solution 2. $M$ is NOT a field (it fails closure under addition).

Key fact: for $\theta\in\mathbb{Q}$, $e^{2\pi i\theta}$ is a root of unity (modulus $1$), so every element $r\,e^{2\pi i\theta}$ of $M$ has rational modulus $|r|$. Counterexample: $1=1\cdot e^{2\pi i\cdot 0}\in M$ and $i=1\cdot e^{2\pi i\cdot(1/4)}\in M$, but $1+i$ has modulus $\sqrt{2}$, which is irrational. So $1+i\notin M$: $M$ is not closed under addition, hence not a field. ∎

↑ Problem

Solution 3. Seven independent subsets; three bases.

Any subset containing $(0,0)$ is dependent (it contains the zero vector), so we only consider subsets of the three nonzero vectors $(0,1),(1,0),(1,1)$.

$\bullet$ Empty set: linearly independent (vacuously). [1]

$\bullet$ Singletons of the three nonzero vectors: each independent. [3]

$\bullet$ Pairs of distinct nonzero vectors: over $\mathbb{F}_2$ the only nonzero scalar is $1$, and $u+v=0\Leftrightarrow u=v$, so any two distinct nonzero vectors are independent. [3]

$\bullet$ Any subset of size $\geq 3$ in a $2$-dimensional space is dependent (e.g. $(0,1)+(1,0)=(1,1)$). [0] Total independent subsets $=1+3+3=7$. (If your course does not count $\emptyset$, it is $6$.) A basis of a $2$-dim space is an independent set of size $2$, so the bases are exactly the three independent pairs: $V$ has $3$ bases. (Check: ordered $=(2^2-1)(2^2-2)=6$, unordered $=6/2!=3$.) ∎

↑ Problem

Solution 4. (a) subspace, (b) not, (c) not, (d) subspace.

(a) $x_1+2x_2+3x_3=0$ is a homogeneous linear condition: $0$ satisfies it, and it is closed under sums and scalar multiples. YES, a subspace.

(b) $x_1+2x_2+3x_3=4$: $(0,0,0)$ does not satisfy it, so NOT a subspace.

(c) $x_1x_2x_3=0$: not closed under $+$. $(1,1,0)$ and $(0,0,1)$ satisfy it, but their sum $(1,1,1)$ has product $1\neq 0$. NOT a subspace.

(d) $x_1=5x_3$, i.e. $x_1-5x_3=0$, is homogeneous linear. YES, a subspace. ∎

↑ Problem

Solution 5. FALSE - a direct-sum complement is not unique. Counterexample:

Work in $V=\mathbb{R}^2$. Let $W=\mathrm{span}((1,0))$ (the $x$-axis), and take $U_1=\mathrm{span}((0,1))$ (the $y$-axis),$U_2=\mathrm{span}((1,1))$ (the diagonal).

$\bullet$ $V=U_1\oplus W$: $(1,0)$ and $(0,1)$ are independent and span $\mathbb{R}^2$, and $U_1\cap W=\{0\}$, so the sum is direct.

$\bullet$ $V=U_2\oplus W$: $(1,1)$ and $(1,0)$ are independent and span $\mathbb{R}^2$, and $U_2\cap W=\{0\}$, so this sum is direct too. But $U_1\neq U_2$ (e.g. $(0,1)\in U_1$ but $(0,1)\notin U_2$). So the claim is false: the same $W$ has two different complements. ∎

↑ Problem

Solution 6. Yes, the new list spans $V$.

Write the new list as $u_k=v_k-v_{k+1}$ for $k=1,\dots,n-1$ and $u_n=v_n$. Each original $v_k$ is a sum of elements of the new list, via a telescoping sum: $v_k=(v_k{-}v_{k+1})+(v_{k+1}{-}v_{k+2})+\cdots+(v_{n-1}{-}v_n)+v_n=u_k+u_{k+1}+\cdots+u_n.$ Hence every $v_k\in\mathrm{span}(u_1,\dots,u_n)$, so $\mathrm{span}(u_1,\dots,u_n)\supseteq\mathrm{span}(v_1,\dots,v_n)=V$. Therefore the new list spans $V$. ∎

↑ Problem

Solution 7. If $(v_1{+}w,\dots,v_n{+}w)$ is dependent, then $w\in\mathrm{span}(v_1,\dots,v_n)$.

Suppose $(v_1{+}w,\dots,v_n{+}w)$ is linearly dependent. Then there are scalars $a_1,\dots,a_n$, not all zero, with $a_1(v_1{+}w)+\cdots+a_n(v_n{+}w)=0$. Regrouping the $w$ terms, $(a_1 v_1+\cdots+a_n v_n) + (a_1+\cdots+a_n)\,w = 0.$Let $s=a_1+\cdots+a_n$.

$\bullet$ If $s=0$, then $a_1 v_1+\cdots+a_n v_n=0$ with the $a_i$ not all zero, contradicting the linear independence of $(v_1,\dots,v_n)$. So this case cannot happen.

$\bullet$ Hence $s\neq 0$, and we may solve for $w$:

$w=-\frac{1}{s}\,(a_1 v_1+\cdots+a_n v_n) \in \mathrm{span}(v_1,\dots,v_n).$∎
