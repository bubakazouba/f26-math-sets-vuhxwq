Solutions

↑ Problem

Solution 1. $91$.

Each $1$-dimensional subspace (line) consists of $0$ together with $q-1$ nonzero vectors, and every nonzero vector lies on exactly one line. So the number of lines is $\frac{q^3-1}{q-1}$. With $q=9$: $\frac{9^3-1}{9-1}=\frac{728}{8}=91$. ∎

↑ Problem

Solution 2. $(q^2+1)(q^2+q+1)=q^4+q^3+2q^2+q+1$.

Count ordered pairs $(v_1,v_2)$ of independent vectors in $F^4$: $v_1$ nonzero gives $q^4-1$ choices, $v_2\notin\mathrm{span}(v_1)$ gives $q^4-q$. Each $2$-dimensional subspace has $(q^2-1)(q^2-q)$ ordered bases, so $\#\{2\text{-dim subspaces}\}=\frac{(q^4-1)(q^4-q)}{(q^2-1)(q^2-q)}=\frac{(q^4-1)(q^3-1)}{(q^2-1)(q-1)}=(q^2+1)(q^2+q+1).$ (Check: $q=2$ gives $5\cdot 7=35$, the Gaussian binomial coefficient for 4 choose 2, base 2.) ∎

↑ Problem

Solution 3. (a) Greedy count.

Build $(v_1,\dots,v_r)$ one vector at a time. A list is independent iff each new vector lies outside the span of the previous ones. Having chosen independent $v_1,\dots,v_i$, their span has $q^i$ vectors, so there are $q^n-q^i$ valid choices for $v_{i+1}$. Multiplying for $i=0,1,\dots,r-1$ gives $(q^n-1)(q^n-q)(q^n-q^2)\cdots(q^n-q^{r-1})$.

(b) An $n\times n$ matrix is invertible iff its $n$ columns form a linearly independent list (a basis of $F^n$). So the count is part (a) with $r=n$: $(q^n-1)(q^n-q)\cdots(q^n-q^{n-1})=|\mathrm{GL}_n(\mathbb{F}_q)|$. That is the link between (a) and (b): invertible matrices $=$ independent length-$n$ column lists.

(c) Over $\mathbb{F}_2$ the probability an $n\times n$ matrix is invertible is $\frac{|\mathrm{GL}_n(\mathbb{F}_2)|}{2^{n^2}}=(1-2^{-1})(1-2^{-2})\cdots(1-2^{-n}).$ This decreases as $n$ grows (values $0.5,\ 0.375,\ 0.328,\ 0.308,\dots$) toward the limit $(1-2^{-1})(1-2^{-2})(1-2^{-3})\cdots\approx 0.2888.$ So for a very large matrix the chance is about 28.9%, NOT 30%. Answer: no. ∎

↑ Problem

Solution 4. $T$ swaps coordinates (matrix rows $(0,1),(1,0)$); characteristic polynomial $\lambda^2-1$.

$Tv=\lambda v$ with $v=(w,z)$ means $(z,w)=(\lambda w,\lambda z)$, i.e. $z=\lambda w$ and $w=\lambda z$, so $\lambda^2=1$.

$\bullet$ If $\mathrm{char}\,F\neq 2$: eigenvalues $\lambda=1$ (eigenvectors $\mathrm{span}(1,1)$) and $\lambda=-1$ (eigenvectors $\mathrm{span}(1,-1)$); the two eigenvalues are distinct, so $T$ is diagonalizable.

$\bullet$ If $\mathrm{char}\,F=2$: then $-1=1$, so $\lambda^2-1=(\lambda-1)^2$ and $\lambda=1$ is the only eigenvalue, with eigenspace $\mathrm{span}(1,1)$ (dimension $1$); $T$ is NOT diagonalizable. So yes, the answer depends on $F$ - specifically on whether $\mathrm{char}\,F=2$. ∎

↑ Problem

Solution 5. Let $\sigma(x)=x_1+\cdots+x_n$, so $Tx=(\sigma(x),\dots,\sigma(x))$.

$\bullet$ Eigenvalue $0$: $Tx=0\Leftrightarrow \sigma(x)=0$, so the $0$-eigenspace is $\{x:x_1+\cdots+x_n=0\}$, dimension $n-1$.

$\bullet$ Eigenvalue $n$: $T(1,\dots,1)=(n,\dots,n)=n\,(1,\dots,1)$, eigenvector $(1,\dots,1)$. (Here $n$ means $n\cdot 1_F$.) If $\mathrm{char}\,F$ does not divide $n$: the eigenvalues $0$ (dim $n-1$) and $n\neq 0$ (dim $1$) give a total of $n$, so $T$ is diagonalizable, with eigenvectors as above. If $\mathrm{char}\,F$ divides $n$ (so $n=0$ in $F$): then $T^2=nT=0$, $T\neq 0$, so $T$ is nilpotent with only eigenvalue $0$; now $(1,\dots,1)$ lies in $\{\sigma=0\}$, whose dimension $n-1<n$, so $T$ is NOT diagonalizable. So yes, the answer depends on $F$ - on whether $\mathrm{char}\,F$ divides $n$. ∎

↑ Problem

Solution 6. $ST$ and $TS$ have the same eigenvalues.

Nonzero $\lambda$: suppose $STv=\lambda v$ with $v\neq 0$. Apply $T$: $T(STv)=\lambda Tv$, i.e. $(TS)(Tv)=\lambda(Tv)$. Moreover $Tv\neq 0$, since $Tv=0$ would give $STv=0=\lambda v$ and hence $v=0$. So $Tv$ is an eigenvector of $TS$ with eigenvalue $\lambda$. By symmetry (swap $S,T$) every nonzero eigenvalue of $TS$ is one of $ST$. $\lambda=0$: $0$ is an eigenvalue of $ST$ iff $ST$ is not invertible. In finite dimensions $ST$ is invertible iff both $S$ and $T$ are invertible - the same condition that makes $TS$ invertible. So $0$ is an eigenvalue of $ST$ iff of $TS$. Hence $ST$ and $TS$ have exactly the same eigenvalues. ∎
