↑ Problem

Solution 1. Take $A=$ the matrix

         [ 2  3  2 ]
    A =  [ 6  3  4 ]
         [ 4  3  3 ]

Every entry is a nonzero integer. Its rows all have the form $a\,(1,0,\frac{1}{2})+b\,(0,1,\frac{1}{3})=(a,b,\frac{a}{2}+\frac{b}{3})$: row 1 is $a{=}2,b{=}3$; row 2 is $a{=}6,b{=}3$; row 3 is $a{=}4,b{=}3$ - so every row lies in the row space of the target RREF, and rows 1,2 are independent (rank $2$). Hence the RREF of $A$ is exactly the given matrix (verified by row reduction). ∎

Solution 3. $R_p$ is a field iff $-1$ is not a square mod $p$.

($R_p=\mathbb{Z}/p[x]/(x^2+1)$, which is a field iff $x^2+1$ is irreducible over $\mathbb{Z}/p$ iff $-1$ is not a square mod $p$.)

(a) $p=2$: $-1=1=1^2$ is a square, so NOT a field (indeed $(1+i)^2=1+2i+i^2=0$, a nonzero zero-divisor). $p=3$: $-1=2$ is not a square mod $3$ ($\{0,1\}$ are the squares), so $R_3$ IS a field - it is $\mathbb{F}_9$. $p=5$: $-1=4=2^2$ is a square, so NOT a field ($(2+i)(2-i)=5\equiv 0$ gives zero-divisors).

(b) $p=53$: from $53=7^2+2^2$ we get $7^2\equiv-2^2\ \mathrm{mod}\ {53}$, so $(7\cdot 2^{-1})^2\equiv-1$. (Concretely $2^{-1}=27$, $7\cdot 27=189\equiv 30$, and $30^2=900\equiv-1\ \mathrm{mod}\ {53}$.) Thus $x^2+1\equiv(x-30)(x+30)$ factors, so $R_{53}$ has zero-divisors and is not a field. (Equivalently $53\equiv 1\ \mathrm{mod}\ 4$, so $-1$ is a square.)

(c) $251\equiv 3\ \mathrm{mod}\ 4$, so $-1$ is NOT a square mod $251$ and $R_{251}$ IS a field ($251^2$ elements). Guess/pattern: for an odd prime, $R_p$ is a field exactly when $p\equiv 3\ \mathrm{mod}\ 4$. ∎

↑ Problem

Solution 4. $\dim\mathrm{null}(ST)=\dim\mathrm{null}(T)+\dim(\mathrm{range}\,T\cap\mathrm{null}\,S)$.

Note $u\in\mathrm{null}(ST)\Leftrightarrow S(Tu)=0\Leftrightarrow Tu\in\mathrm{null}(S)$. Restrict $T$ to the subspace $\mathrm{null}(ST)$:

$\bullet$ Image: for $u\in\mathrm{null}(ST)$, $Tu\in\mathrm{range}(T)\cap\mathrm{null}(S)$; and every $v=Tu$ in that intersection has $STu=Sv=0$, so $u\in\mathrm{null}(ST)$. Hence $T$ maps $\mathrm{null}(ST)$ ONTO $\mathrm{range}(T)\cap\mathrm{null}(S)$.

$\bullet$ Kernel: $\{u\in\mathrm{null}(ST):Tu=0\}=\mathrm{null}(T)$ (and $\mathrm{null}(T)\subseteq\mathrm{null}(ST)$). Applying rank-nullity to $T|_{\mathrm{null}(ST)}$ gives $\dim\mathrm{null}(ST)=\dim\mathrm{null}(T)+\dim(\mathrm{range}\,T\cap\mathrm{null}\,S)$. ∎

↑ Problem

Solution 5. Let $S=T=$ projection onto the $x$-axis: $S(x,y)=T(x,y)=(x,0)$.

Then $\mathrm{null}(S)=\mathrm{null}(T)=\{(0,y)\}$, each $1$-dimensional. But $ST(x,y)=S(x,0)=(x,0)$, so $\mathrm{null}(ST)=\{(0,y)\}$ is $1$-dimensional, not $2$-dimensional. (Check via prob. 4: $\mathrm{range}\,T=x$-axis, $\mathrm{null}\,S=y$-axis, intersection $\{0\}$, so $\dim\mathrm{null}(ST)=1+0=1$.) ∎

↑ Problem

Solution 6. (a) $\mathrm{null}(T)=\{0\}$ iff $T$ preserves linear independence.

($\Rightarrow$) Let $(v_1,\dots,v_p)$ be independent and $a_1 Tv_1+\cdots+a_p Tv_p=0$. Then $T(a_1v_1+\cdots+a_pv_p)=0$, so $a_1v_1+\cdots+a_pv_p\in\mathrm{null}(T)=\{0\}$; independence forces all $a_i=0$. So $(Tv_i)$ is independent.

($\Leftarrow$) If $v\neq 0$ then $(v)$ is independent, so $(Tv)$ is independent, so $Tv\neq 0$. Hence $\mathrm{null}(T)=\{0\}$.

(b) $\mathrm{range}(T)=W$ iff $T$ preserves spanning.

($\Rightarrow$) If $(v_1,\dots,v_q)$ spans $V$ and $w\in W$, write $w=Tv=T(\sum a_i v_i)=\sum a_i Tv_i$, so $(Tv_i)$ spans $W$.

($\Leftarrow$) $V$ has a spanning list (a basis); its image spans $W$, so $\mathrm{range}(T)=W$.

(c) $T$ invertible iff $T$ sends each basis to a basis.

($\Rightarrow$) A basis is independent and spanning; by (a),(b) its image is independent and spanning, i.e. a basis.

($\Leftarrow$) Take a basis $(v_1,\dots,v_n)$ of $V$; its image is a basis of $W$, so $T$ is onto and $\dim W=n=\dim V$; a surjection between equal finite dimensions is injective, so $T$ is invertible. ∎
