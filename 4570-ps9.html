MATH 4570 · Problem Set 9 (with solutions)

Source: MIT 18.700 Linear Algebra, Fall 2013 (MIT OpenCourseWare, CC BY-NC-SA), Problem Set 9. Self-contained (skew-adjoint operators; the real block-diagonal form). Inner product linear in the first slot. Solutions by Claude.

Problems

Call $S\in\mathcal{L}(V)$ skew-adjoint if $S^*=-S$.

1. $V$ complex and finite-dimensional, $S$ skew-adjoint. Show the eigenvalues of $S$ are purely imaginary, and $V$ is the orthogonal direct sum of the eigenspaces $V_{i\lambda}$ ($\lambda\in\mathbb{R}$).

Solution ↓

2. $V$ an $n$-dimensional REAL inner-product space, $S$ skew-adjoint.

(a) Show $Sv\perp v$ for all $v$. (b) Show every eigenvalue of $S^2$ is a real number $\leq 0$.

(c) If $S^2=-I$, show $(a+bi)v:=av+bSv$ and $\langle v,w\rangle_{\mathbb{C}}:=\langle v,w\rangle-i\langle Sv,w\rangle$ make $V$ a complex inner-product space. What is $\dim_{\mathbb{C}}V$? (d) In general, find an orthonormal basis putting $S$ in block-diagonal form with $2\times 2$ blocks $\left(\text{rows }(0,-\lambda),(\lambda,0)\right)$, $\lambda>0$, and $1\times 1$ zero blocks.

Solution ↓

3. Give a complex square matrix with exactly three distinct eigenvalues that is not diagonalizable.

Solutions

↑ Problem

Solution 1. Eigenvalues purely imaginary; $S$ is normal.

If $Sv=\mu v$ with $v\neq 0$, then $\mu\langle v,v\rangle=\langle Sv,v\rangle=\langle v,S^*v\rangle=\langle v,-Sv\rangle=-\overline{\mu}\langle v,v\rangle$. As $\langle v,v\rangle\neq 0$, $\mu=-\overline{\mu}$, i.e. $\mathrm{Re}\,\mu=0$: $\mu$ is purely imaginary, $\mu=i\lambda$ with $\lambda\in\mathbb{R}$. Also $S$ is normal: $SS^*=S(-S)=-S^2=(-S)S=S^*S$. By the complex spectral theorem a normal operator has an orthonormal basis of eigenvectors, so $V$ is the orthogonal direct sum of its eigenspaces, which are the $V_{i\lambda}$; hence $V=\bigoplus_{\lambda\in\mathbb{R}}V_{i\lambda}$ (only finitely many $\lambda$ occur). ∎

↑ Problem

Solution 2. (a) $\langle Sv,v\rangle=\langle v,S^*v\rangle=\langle v,-Sv\rangle=-\langle Sv,v\rangle$ (real, symmetric).

So $2\langle Sv,v\rangle=0$, giving $\langle Sv,v\rangle=0$, i.e. $Sv\perp v$.

(b) $S^2$ is self-adjoint: $(S^2)^*=(S^*)^2=(-S)^2=S^2$, so its eigenvalues are real. If $S^2v=\mu v$ ($v\neq0$), $\mu\langle v,v\rangle=\langle S^2v,v\rangle=\langle Sv,S^*v\rangle=\langle Sv,-Sv\rangle=-\|Sv\|^2\leq 0$, so $\mu\leq 0$.

(c) With $S^2=-I$, the operator $S$ plays the role of `$i$': $i^2v=S^2v=-v$. One checks the vector-space and inner-product axioms directly (e.g. $\langle v,w\rangle_{\mathbb{C}}$ is $\mathbb{C}$-linear in $v$, conjugate-symmetric, and positive since $\langle v,v\rangle_{\mathbb{C}}=\langle v,v\rangle-i\langle Sv,v\rangle=\langle v,v\rangle>0$ by (a)). Each complex dimension is two real dimensions, so $\dim_{\mathbb{C}}V=n/2$ (in particular $n$ is even).

(d) By (b), $S^2$ is self-adjoint with eigenvalues $\leq 0$; the real spectral theorem gives an orthogonal decomposition of $V$ into $S^2$-eigenspaces. On $\mathrm{null}\,S^2$: $\langle Sv,Sv\rangle=-\langle S^2v,v\rangle=0$, so $Sv=0$ - these are the $1\times 1$ zero blocks. On an eigenspace for $-\lambda^2$ ($\lambda>0$): for a unit $u$, the pair $u,\ Su/\lambda$ is orthonormal ($\langle u,Su\rangle=0$, $\|Su\|^2=-\langle S^2u,u\rangle=\lambda^2$) and $S$-invariant, with $Su=\lambda(Su/\lambda)$ and $S(Su/\lambda)=S^2u/\lambda=-\lambda u$ - a $2\times 2$ block $\left(\text{rows }(0,-\lambda),(\lambda,0)\right)$. Peeling off such blocks and ordering $\lambda_1\geq\cdots\geq\lambda_r>0$ gives the stated form. ∎

↑ Problem

Solution 3. A Jordan block plus two more eigenvalues.

Take the $4\times 4$ complex matrix

        [ 1  1  0  0 ]
    A = [ 0  1  0  0 ]
        [ 0  0  2  0 ]
        [ 0  0  0  3 ]

Its characteristic polynomial is $(\lambda-1)^2(\lambda-2)(\lambda-3)$, so the eigenvalues are exactly $1,2,3$ (three distinct). But $A-I$ has rank $3$, so the eigenspace for $\lambda=1$ has dimension $4-3=1<2$, the algebraic multiplicity. A matrix is diagonalizable only if every eigenvalue's geometric multiplicity equals its algebraic multiplicity, so $A$ is not diagonalizable. ∎
