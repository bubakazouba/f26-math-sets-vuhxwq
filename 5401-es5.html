5(g). $T=\{z\in\mathbb{C}^*: |z|=1\}$ is the circle group. $\mathbb{C}^*$ is abelian, so left and right cosets coincide. For $w\in\mathbb{C}^*$: $w\in zT$ iff $|w/z|=1$ iff $|w|=|z|$. So the coset $zT$ is the circle $\{w: |w|=|z|\}$ of radius $|z|$ centered at 0. The cosets are exactly the circles $rT$, one for each radius $r>0$ (infinitely many). ∎

5(h). $[S_4:H]=24/3=8$, so there are 8 left and 8 right cosets.

Left cosets $\sigma H$: $\{(1),(1\,2\,3),(1\,3\,2)\}$, $\{(1\,2),(1\,3),(2\,3)\}$, $\{(3\,4),(1\,2\,4\,3),(1\,4\,3\,2)\}$, $\{(1\,4),(1\,2\,3\,4),(1\,3\,2\,4)\}$,

$\{(2\,4),(1\,3\,4\,2),(1\,4\,2\,3)\}$, $\{(1\,4\,2),(2\,3\,4),(1\,3)(2\,4)\}$, $\{(1\,4\,3),(2\,4\,3),(1\,2)(3\,4)\}$, $\{(1\,2\,4),(1\,3\,4),(1\,4)(2\,3)\}$.

Right cosets $H\sigma$: $\{(1),(1\,2\,3),(1\,3\,2)\}$, $\{(1\,2),(1\,3),(2\,3)\}$, $\{(3\,4),(1\,2\,3\,4),(1\,3\,4\,2)\}$, $\{(1\,4),(1\,4\,2\,3),(1\,4\,3\,2)\}$,

$\{(2\,4),(1\,2\,4\,3),(1\,3\,2\,4)\}$, $\{(1\,3\,4),(2\,3\,4),(1\,2)(3\,4)\}$, $\{(1\,2\,4),(2\,4\,3),(1\,3)(2\,4)\}$, $\{(1\,4\,2),(1\,4\,3),(1\,4)(2\,3)\}$.

Sample check: $(3\,4)(1\,2\,3)$ sends $1\to2$, $2\to3\to4$, $4\to3$, $3\to1$, so it is $(1\,2\,4\,3)$. Only the first two cosets are both left and right cosets, so $H$ is not normal in $S_4$. ∎

10. Two cosets $z+\mathbb{R}$ and $w+\mathbb{R}$ are equal iff $z-w\in\mathbb{R}$, i.e. iff $\mathrm{Im}\,z=\mathrm{Im}\,w$. So the cosets are the horizontal lines $bi+\mathbb{R}$, $b\in\mathbb{R}$, and distinct $b$ give distinct cosets. There are infinitely many (uncountably many) of them, so $[\mathbb{C}:\mathbb{R}]$ is infinite. ∎

2. $D_4=\{e,r,r^2,r^3,s,rs,r^2s,r^3s\}$ with $r^4=s^2=e$ and $srs=r^{-1}$ ($r$ = rotation by $90^\circ$, $s$ = a reflection). By Lagrange the orders are 1, 2, 4, 8. There are 10 subgroups:

Order 1: $\{e\}$. Order 2: $\langle r^2\rangle$, $\langle s\rangle$, $\langle rs\rangle$, $\langle r^2s\rangle$, $\langle r^3s\rangle$. Order 4: $\langle r\rangle=\{e,r,r^2,r^3\}$, $\{e,r^2,s,r^2s\}$, $\{e,r^2,rs,r^3s\}$. Order 8: $D_4$.

(Order 4 is complete: the only elements of order 4 are $r,r^3$, giving $\langle r\rangle$. A non-cyclic order-4 subgroup is $\{e,x,y,xy\}$ with $x,y,xy$ of order 2 commuting; it contains $r^2$, because the product of two distinct commuting reflections is $r^2$. That forces the two listed.)

Normal: $\{e\}$, $D_4$; $\langle r^2\rangle=Z(D_4)$ (as $r^2$ commutes with everything); and the three order-4 subgroups (index 2, see 10.10). Not normal: the four reflection subgroups, e.g. $$\begin{aligned}r\,s\,r^{-1} &= r\cdot rs\\ &= r^2s\notin\langle s\rangle\end{aligned}$$ (using $sr^{-1}=rs$), and similarly $r(rs)r^{-1}=r^3s\notin\langle rs\rangle$. So 6 normal subgroups.

Factor groups: $D_4/\{e\}\cong D_4$. $D_4/\langle r^2\rangle$ has order 4, and every element squares into $\langle r^2\rangle$ ($r^2$, and each reflection squares to $e$), so every non-identity coset has order 2: $\cong\mathbb{Z}_2\times\mathbb{Z}_2$. Each index-2 quotient has order 2: $\cong\mathbb{Z}_2$. $D_4/D_4\cong\{e\}$ (trivial). So up to isomorphism: $D_4$, $\mathbb{Z}_2\times\mathbb{Z}_2$, $\mathbb{Z}_2$, $\{e\}$. ∎

3. $Q_8=\{\pm1,\pm I,\pm J,\pm K\}$ with $I^2=J^2=K^2=-1$, $IJ=K$, $JK=I$, $KI=J$. $-1$ is the only element of order 2 and the other six ($\pm I,\pm J,\pm K$) have order 4. Subgroups (6 in total):

$\{1\}$; $\{\pm1\}$; $\langle I\rangle=\{\pm1,\pm I\}$, $\langle J\rangle=\{\pm1,\pm J\}$, $\langle K\rangle=\{\pm1,\pm K\}$; $Q_8$. (Any order-4 subgroup contains an element of order 4, since $-1$ is the only involution, so it is one of the three cyclic ones. Any subgroup containing two of $\pm I,\pm J,\pm K$ from different pairs contains their product and so is all of $Q_8$.)

Normal: ALL six. $\{1\}$ and $Q_8$ always; $\{\pm1\}=Z(Q_8)$ since $-1$ commutes with everything; $\langle I\rangle,\langle J\rangle,\langle K\rangle$ have index 2.

Factor groups: $Q_8/\{1\}\cong Q_8$. $Q_8/\{\pm1\}$ has order 4 and every element squares to $\pm1$, so every non-identity coset has order 2: $\cong\mathbb{Z}_2\times\mathbb{Z}_2$. $$\begin{aligned}Q_8/\langle I\rangle &\cong Q_8/\langle J\rangle\\ &\cong Q_8/\langle K\rangle\\ &\cong \mathbb{Z}_2\end{aligned}.$$ $Q_8/Q_8\cong\{e\}$. So up to isomorphism: $Q_8$, $\mathbb{Z}_2\times\mathbb{Z}_2$, $\mathbb{Z}_2$, $\{e\}$. ∎

10. Since $[G:H]=2$, the two left cosets are $H$ and $G\setminus H$, and the two right cosets are also $H$ and $G\setminus H$. If $g\in H$, then $gH=H=Hg$. If $g\notin H$, then $gH\neq H$ and $Hg\neq H$, so $gH=G\setminus H=Hg$. Thus $gH=Hg$ for all $g$, and $H$ is normal.

For $n\geq3$: $A_n$ has index 2 in $S_n$, since $|A_n|=n!/2$. So $A_n$ is normal. It is proper, and it is nontrivial since $|A_n|=n!/2\geq3$ (it contains $(1\,2\,3)$). So $S_n$ has a proper nontrivial normal subgroup and is not simple. ∎

12. Subgroup: $eg=ge$, so $e\in C(g)$. If $x,y\in C(g)$, then $(xy)g=x(gy)=(xg)y=g(xy)$, so $xy\in C(g)$. Multiplying $xg=gx$ on both sides by $x^{-1}$ gives $gx^{-1}=x^{-1}g$, so $x^{-1}\in C(g)$.

Normality: suppose $\langle g\rangle$ is normal in $G$. Let $a\in G$ and $x\in C(g)$. Since $\langle g\rangle$ is normal, $a^{-1}ga\in\langle g\rangle$, say $a^{-1}ga=g^m$. As $x$ commutes with $g$, it commutes with $g^m$. Then

$$(axa^{-1})\,g\,(axa^{-1})^{-1}=ax(a^{-1}ga)x^{-1}a^{-1}=a(xg^mx^{-1})a^{-1}=ag^ma^{-1}=a(a^{-1}ga)a^{-1}=g.$$

So $axa^{-1}$ commutes with $g$, i.e. $aC(g)a^{-1}\subseteq C(g)$ for every $a$. Hence $C(g)$ is normal. ∎

14. Write $[x,y]=xyx^{-1}y^{-1}$. Note $[x,y]^{-1}=yxy^{-1}x^{-1}=[y,x]$, so $G'$ is the set of finite products of commutators, and it is closed under products and inverses.

(a) For $g\in G$, conjugation $c_g(z)=gzg^{-1}$ is a homomorphism and $c_g([x,y])=[gxg^{-1},gyg^{-1}]$ is again a commutator. So $c_g$ sends a product of commutators to a product of commutators: $gG'g^{-1}\subseteq G'$ for all $g$. Hence $G'$ is normal in $G$.

(b) For $a,b\in G$: $(aN)(bN)=(bN)(aN)$ iff $abN=baN$ iff $(ba)^{-1}ab=a^{-1}b^{-1}ab\in N$. As $a,b$ range over $G$, $a^{-1}b^{-1}ab=[a^{-1},b^{-1}]$ ranges over every commutator. So $G/N$ is abelian iff $N$ contains every commutator. Since $N$ is a subgroup, that holds iff $N$ contains all finite products of commutators, i.e. $G'\subseteq N$. ∎

5. $U(5)=\{1,2,3,4\}$: $2^1=2$, $2^2=4$, $2^3=8\equiv3$, $2^4\equiv1$, so $U(5)=\langle2\rangle$ is cyclic of order 4. $U(10)=\{1,3,7,9\}$: $3^2=9$, $3^3=27\equiv7$, $3^4\equiv1$, so $U(10)=\langle3\rangle$ is cyclic of order 4. Two cyclic groups of the same order are isomorphic (e.g. $2^k\mapsto3^k$), so $U(5)\cong U(10)$.

$U(12)=\{1,5,7,11\}$: $5^2=25\equiv1$, $7^2=49\equiv1$, $11^2=121\equiv1$. So $U(12)$ has no element of order 4 and is not cyclic. An isomorphism preserves element orders, so $U(12)$ is not isomorphic to $U(5)$. ∎

8. $\mathbb{Z}=\langle1\rangle$ is cyclic, and an isomorphic image of a cyclic group is cyclic ($\phi(\langle g\rangle)=\langle\phi(g)\rangle$). So it suffices to show $\mathbb{Q}$ is not cyclic. Suppose $\mathbb{Q}=\langle p/q\rangle$ with $q>0$. Then $p\neq0$ (since $\langle0\rangle=\{0\}$). Now $\frac{p}{2q}\in\mathbb{Q}$ would equal $n\cdot\frac{p}{q}$ for some integer $n$, giving $n=\frac{1}{2}$, a contradiction. So $\mathbb{Q}$ is not isomorphic to $\mathbb{Z}$. ∎

28. Since $p\geq2$, pick $g\neq e$ in $G$. By Lagrange, $|g|$ divides $p$ and $|g|\neq1$, so $|g|=p$ and $G=\langle g\rangle=\{e,g,\ldots,g^{p-1}\}$. Define $\phi:\mathbb{Z}_p\to G$ by $\phi(k)=g^k$. This is well defined because $g^p=e$. It is a homomorphism: $\phi(k+l)=g^{k+l}=g^kg^l$ (exponents mod $p$). It is a bijection, since $g^0,\ldots,g^{p-1}$ are the $p$ distinct elements of $G$. So $G\cong\mathbb{Z}_p$. ∎

29. Regard $S_n\subseteq S_{n+2}$ (fixing $n+1,n+2$) and let $\tau=(n{+}1\;\,n{+}2)$. Then $\tau$ commutes with every $\sigma\in S_n$ (disjoint supports) and $\tau^2=e$. Let $\varepsilon(\sigma)\in\{0,1\}$ be the parity of $\sigma$ (0 even, 1 odd), so $\varepsilon(\alpha\beta)\equiv\varepsilon(\alpha)+\varepsilon(\beta)$ (mod 2). Define $\phi:S_n\to S_{n+2}$ by $\phi(\sigma)=\sigma\tau^{\varepsilon(\sigma)}$.

Image in $A_{n+2}$: if $\sigma$ is even, $\phi(\sigma)=\sigma$ is even; if $\sigma$ is odd, $\sigma\tau$ is odd times odd, so even.

Homomorphism: $$\begin{aligned}\phi(\alpha)\phi(\beta) &= \alpha\tau^{\varepsilon(\alpha)}\beta\tau^{\varepsilon(\beta)}\\ &= \alpha\beta\,\tau^{\varepsilon(\alpha)+\varepsilon(\beta)}\\ &= \alpha\beta\,\tau^{\varepsilon(\alpha\beta)}\\ &= \phi(\alpha\beta)\end{aligned},$$ using that $\tau$ commutes with $\beta$ and $\tau^2=e$.

One-to-one: if $\phi(\sigma)=e$, then restricting to $\{1,\ldots,n\}$ (where $\tau$ acts trivially) shows $\sigma=e$. So $\phi$ is an isomorphism of $S_n$ onto the subgroup $\phi(S_n)$ of $A_{n+2}$. ∎

1. Write $p$ as a product of disjoint cycles of lengths $\ell_1,\ldots,\ell_k$, counting 1-cycles, so $\ell_1+\cdots+\ell_k=n$. An $\ell$-cycle is a product of $\ell-1$ transpositions: $(a_1\,\ldots\,a_\ell)=(a_1\,a_\ell)\cdots(a_1\,a_2)$. A 1-cycle uses 0. So $p$ is a product of $\sum_i(\ell_i-1)=n-k$ transpositions. The parity of a permutation is well defined, so the parity of $p$ equals the parity of $n-k$. ∎

2. Key fact: if $\alpha$ sends $a\mapsto b$, then $\gamma\alpha\gamma^{-1}$ sends $\gamma(a)\mapsto\gamma(b)$, since $\gamma\alpha\gamma^{-1}(\gamma(a))=\gamma(\alpha(a))$. So if $\alpha=(a_1\,\ldots\,a_\ell)(b_1\,\ldots\,b_m)\cdots$ (all cycles, including 1-cycles), then

$$\gamma\alpha\gamma^{-1}=(\gamma(a_1)\,\ldots\,\gamma(a_\ell))(\gamma(b_1)\,\ldots\,\gamma(b_m))\cdots.$$

($\Rightarrow$) So conjugates have the same cycle type. ($\Leftarrow$) If $\alpha,\beta$ have the same cycle type, write both in disjoint cycle form (with 1-cycles), with the cycles of $\beta$ listed in the same length order as those of $\alpha$. Define $\gamma$ to send the $j$-th entry of each cycle of $\alpha$ to the $j$-th entry of the corresponding cycle of $\beta$. Both cycle lists partition $\{1,\ldots,n\}$, so $\gamma$ is a bijection, i.e. $\gamma\in S_n$. By the displayed formula, $\gamma\alpha\gamma^{-1}=\beta$. ∎
